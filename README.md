# 零花钱管家 CAD · 最终重做版（无登录）

## 文件
- `index.html`：完整应用
- `manifest.json`：PWA 主屏幕配置
- `sw.js`：离线缓存

## GitHub Pages 发布（不要上传 ZIP 本身代替文件）
1. 解压本 ZIP。
2. 将以上三个文件上传到仓库所选发布目录的最外层。
3. 仓库 Settings → Pages → Build and deployment：选择 Deploy from a branch，Branch 选 main，Folder 选 /(root)（若你选择 /docs，则文件必须放在 docs 目录）。
4. 保存后在 Settings → Pages 点击 Visit site。首次部署可能需要等待数分钟。
5. 如果仓库名为 `预算应用`，项目站点 URL 通常带有 `/预算应用/` 路径；以 Visit site 显示的 URL 为准。
6. iPhone Safari 打开 → 分享 → 添加到主屏幕。

## 功能
- CAD 初始总预算 $1,830；分类初始分配：游戏 $550、零食 $480、大件储蓄 $500、自由与备用 $300。
- 日常消费按预算周期开始日期划分周，使用周额度并支持未用额度结转；大件消费不占周额度。
- 全年余额校验、分类额度校验、额外收入、分类预算转账和转账撤销（删除转账记录会反向恢复额度）。
- 消费记录编辑、删除、备注搜索、日期筛选；周总结、月总结、近 6 个月趋势、近 6 个预算周走势。
- 购买前模拟、通用大件省钱替代建议、分类预算重分配、JSON 导入导出。
- 数据只存在当前浏览器的 localStorage，不会自动云同步；定期导出备份。

## 预算原则
分类预算只是全年资金的分配，不会与总余额重复计算。消费同时减少总余额与相应分类剩余额度；额外收入增加总余额。大件消费也必须有足够总余额和分类额度。日常消费受相应预算周的可用额度限制。
本应用没有账号系统。GitHub Pages 内容可能公开，切勿将密码或私人资料写进源代码。

## 新增：灵活每周消费上限（自动节流）
在“设置与备份”开启“自动节流”，并设置希望在预算周期结束时保留的金额。应用会按当前总余额减去保留金额，再除以预算周期剩余周数，计算当前有效每周日常上限；计算值不会高于你设置的基础周额度。记录大件消费后，当前余额下降，系统会重新计算有效上限。关闭开关即可恢复固定每周额度。请注意：自动节流会基于当前余额重新估算，历史周统计也会用当前有效上限作比较；它不会自动转移分类预算。
